# 01 · 认识 HPC：节点、作业与 Slurm

本章介绍 HPC 的组成与各部分的用途，以及"申请资源"的具体含义。

## 概览

HPC（高性能计算集群）是由多台服务器组成的共享计算资源，运作方式类似一栋**按预约使用的公共实验楼**：

| 实验楼 | HPC 中的对应 | 用途 |
|---|---|---|
| 大厅 | **登录节点** | 登录、整理文件、提交预约；不在此做实验 |
| 实验间 | **计算节点** | 预约成功后，程序在这里运行 |
| 预约系统 | **Slurm** | 排队、分配实验间、到时收回 |
| 预约单 | **作业脚本** | 写明所需的 CPU 核数、内存、时长和要运行的命令 |
| 按时收费 | **计费** | 按占用的核数 × 时间计费，由导师经费支付 |

一次完整的使用流程：

**本机编写代码 → SSH 登录 → 上传代码 → 提交作业 → 排队 → 在计算节点运行 → 下载结果**

## 两种节点

HPC 集群是一组通过高速网络连接的服务器，每台服务器称为一个**节点（node）**。日常使用涉及两种节点：

| | 登录节点（login node） | 计算节点（compute node） |
|---|---|---|
| 进入方式 | SSH 直接登录 | 通过 Slurm 申请，分配后才能使用 |
| 用途 | 编辑文件、传输数据、使用 Git、提交和查询作业 | 训练、评估、编译、调试 |
| 不应进行 | 训练、大规模数据处理、长时间占满 CPU 的程序 | 超出申请量使用资源 |
| 使用者 | 所有用户共用 | 申请到的核和内存仅供本作业使用 |

> **注意：** 登录节点是所有用户共用的入口。在登录节点上运行训练会影响其他用户，进程也可能被管理员终止。

**判断当前所在节点：** 执行 `hostname` 查看主机名；在计算节点的作业中，`echo "$SLURM_JOB_ID"` 输出作业号，在登录节点上则为空。

## 作业：一次资源申请

**作业（job）** 由一份资源申请和要执行的命令组成。提交作业时需要向 Slurm 说明：

- 使用的**分区（partition）**：一类计算节点的集合，如普通 CPU、A40 GPU、免费调试。分区也常称为"队列"。
- 所需的 **CPU 核**、**内存**和 **GPU** 数量。
- 最长运行时间（**时间上限**）。
- 要运行的命令。

**Slurm** 是集群的作业调度系统，负责排队、将作业分配到合适的计算节点，并在时间到达后收回资源。每个作业有唯一的**作业号（job ID）**。

申请得到的不是一台独占的服务器，而是某台计算节点上的一部分核、内存和时间。作业结束（正常完成、出错、超时或被取消）后，这些资源即被收回。

## 作业的生命周期

```text
sbatch 提交 → PENDING 排队 → RUNNING 运行 → 结束（COMPLETED / FAILED / TIMEOUT / CANCELLED）
```

| 状态 | `squeue` 中的缩写 | 是否占用资源并计费 |
|---|---|---|
| 排队（PENDING） | `PD` | 不占用，不计费 |
| 运行（RUNNING） | `R` | **占用并计费**，程序空转同样计费 |
| 已结束 | 不再显示 | 资源已自动释放 |

## 二期常用分区

| 分区 | 用途 | 费用 |
|---|---|---|
| `debug` | 短时调试，最长 30 分钟 | 免费 |
| `i64m512u` | 普通 CPU 计算 | 0.02 元/核·小时 |
| `i64m1tga40u` | A40 GPU 计算 | 0.50 元/卡·小时，CPU 另计 |

分区名、上限和价格以平台实时配置为准。查询方法见 [Slurm 作业](04-slurm-basics.md)，计费细节见 [费用与预算](08-pricing-and-budget.md)。

## HKUST(GZ) 的 HPC 平台

学校有多期 HPC 平台，登录地址和使用方式各不相同。**本手册只涉及二期。**

| 平台 | 登录地址 | 说明 |
|---|---|---|
| **二期** | `hpc2login.hpc.hkust-gz.edu.cn` | **本手册范围**：CPU + NVIDIA GPU，使用 Slurm |
| 一期 | `hpc1login.hpc.hkust-gz.edu.cn` | 使用 `jsub` / `jjobs`，本手册的 Slurm 命令不适用 |
| 三期（ACD） | `hpc3login.hpc.hkust-gz.edu.cn` | 不开放互联网，规则不同，见官方三期手册 |
| 四期（国产） | `hpc4login.hpc.hkust-gz.edu.cn` | 国产硬件平台，环境不能直接套用 |
| EDA | — | 电子设计自动化专用平台 |

拥有账号不代表可以使用所有平台，可用平台以实际开通情况为准。

> **提示：** 登录后显示的主机名（如 `mgmt-3`、`mgmt-4`）只是管理节点的名称，**不代表**所在平台是三期或四期。平台以 SSH 连接的地址为准。

本手册的流程不需要 Docker，Python 虚拟环境（venv 或 conda）通常已足够。
