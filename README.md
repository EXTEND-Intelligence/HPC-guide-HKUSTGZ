# HKUST(GZ) HPC 新生上手指南

写给第一次使用港科大（广州）HPC 的同学：用最短的路径学会登录集群、提交作业、取回结果，并且不浪费经费。

本指南只讲最常用的路线：**二期集群 + SSH + Slurm**。它是官方文档的入门导读，完整、最新的说明以 [官方文档](https://docs.hpc.hkust-gz.edu.cn/) 为准。

## 一分钟理解 HPC

HPC（高性能计算集群）是很多台服务器组成的共享计算资源。可以把它想象成一栋**需要预约的公共实验楼**：

| 实验楼 | HPC 里对应的 | 你在这里做什么 |
|---|---|---|
| 大厅 | **登录节点** | 登录、整理文件、提交预约。不在这里做实验 |
| 实验间 | **计算节点** | 预约成功后，程序在这里真正运行 |
| 预约系统 | **Slurm** | 排队、分配实验间、到点收回 |
| 预约单 | **作业脚本** | 写明要几个 CPU 核、多少内存、用多久、运行什么命令 |
| 按时收费 | **计费** | 按占用的核数 × 时间计费，由导师经费支付 |

所以一次完整的使用流程是：

**本机写代码 → SSH 登录 → 上传代码 → 提交作业 → 排队 → 在计算节点运行 → 下载结果**

## 新手必记 5 条

1. **不要在登录节点上跑训练。** 训练、评估和大量计算都要通过 Slurm 提交到计算节点。
2. **提交不等于运行。** `sbatch` 只是交了预约单；状态 `PD` 表示还在排队，`R` 才是正在运行。
3. **作业在运行就在计费。** 程序空转也照样收费。不需要的作业用 `scancel 作业号` 取消；断开 SSH 不会让作业停下来。
4. **先用免费的 `debug` 分区试跑。** 它最长 30 分钟、只用于调试；确认没问题再提交正式作业。
5. **自己备份重要结果。** 平台不承诺永久保存数据。
