## 与旧示例容易冲突的地方

- 官方二期作业页有 `acd_u`、`normal` 等不同平台的示例名字；本教程按二期队列表使用 `i64m512u` / `debug` / `i64m1tga40u`。
- 对单个 Python 进程，使用 `--ntasks=1 --cpus-per-task=N`，而非把 `-n N` 当成每进程核心数。
- `mgmt-4` 是管理节点名，不表示四期。
- 官网简介的“四大集群”和新手册单列的“四期”不能简单等同；用户权限需单独确认。
- 不根据历史账户配额推断今天的并行数；用 `sacctmgr` / 分区查询，受限时咨询管理员。

更新价格/队列时，同时检查教程、脚本、预算算例；引用来源见 [官方链接](official-links.md)。
